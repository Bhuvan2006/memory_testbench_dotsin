# Step 2: Scenario Generator, Mock Model, Tests Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A seeded, deterministic 40-turn synthetic scenario with 12 planted facts and 12 recall questions, plus an offline mock model that answers only from the context it is given.

**Architecture:** `data/generate_scenario.py` builds the scenario as a plain dict and writes `data/scenario.json`. `src/mock_model.py` is a rule-based model with the same call shape the Agno adapter will use in step 3. Tests run offline with pytest.

**Tech Stack:** Python 3.13, pytest. No Agno yet (pinned in step 3, after it is installed and inspected).

**Spec:** `PROJECT_B_BUILD_BRIEF.md` sections 2.1 and 7 (step 2 of section 6).

## Global Constraints

- Synthetic data only. Fictional names and values.
- Scenario generation is deterministic: `random.Random(7)`, no clock, no network.
- Mock mode is free and offline.
- Token counts from the mock are labelled synthetic (word count), never presented as provider usage.

## Review Focus

1. Empty or whitespace-only user message: the scenario must never contain one. Task 1 test `test_no_empty_turns`.
2. Duplicate needle key: two facts with the same key would make recall ambiguous. Task 1 test `test_needle_keys_unique`.
3. Recall keyword appearing in a tool output (false match): the scorer must not count a tool dump as an answer. Task 2 test `test_tool_output_does_not_answer`.
4. Number formatting in answers (`40k` vs `40,000` vs `40000`): the expected answer is a fixed substring the scorer uses. Task 1 test `test_expected_answers_are_plain_substrings`.
5. Context that lacks the fact: the mock must say it does not know, not guess. Task 2 test `test_missing_fact_returns_unknown`.

## Decisions made here (not in the brief)

- Recall turns are **29-40** (12 turns). The brief says "turns 30-40", which is only 11 turns for 12 questions. Flagged for your review.
- Needle 4 (budget) is **updated** at turn 20 from `40k` to `35k`. Recall expects `35`. This tests contradiction handling; the brief asks for a "wrong or contradicted" count.
- Calendar dump appears at turns 5, 15, 25, 35. Each dump is a seeded list of 60 event lines (about 1,500 tokens by word count times 1.3).
- Persona: fictional "Rowan", a product analyst.

**Interfaces:**
- Consumes: nothing.
- Produces:
  - `build_scenario(seed: int = 7) -> dict`
  - Scenario shape: `{"turns": list[Turn], "recall": list[Recall], "needles": list[Needle]}`
  - `Turn = {"index": int, "user": str, "tool_output": str | None}` (index 1..40)
  - `Needle = {"key": str, "turn": int, "value": str, "update_turn": int | None, "new_value": str | None}`
  - `Recall = {"turn": int, "needle_key": str, "question": str, "expected": str}`
  - `main()` writes `data/scenario.json` (`json.dumps(..., indent=2, sort_keys=True)`).

```python
# tests/test_scenario.py
import json
from pathlib import Path
from data.generate_scenario import build_scenario

SCEN = build_scenario(seed=7)

def test_forty_turns_numbered_1_to_40():
    assert [t["index"] for t in SCEN["turns"]] == list(range(1, 41))

def test_twelve_needles_in_turns_2_to_12():
    assert len(SCEN["needles"]) == 12
    assert all(2 <= n["turn"] <= 12 for n in SCEN["needles"])

def test_twelve_recall_questions_in_turns_29_to_40():
    assert len(SCEN["recall"]) == 12
    assert all(29 <= r["turn"] <= 40 for r in SCEN["recall"])

def test_needle_keys_unique():
    keys = [n["key"] for n in SCEN["needles"]]
    assert len(keys) == len(set(keys))

def test_no_empty_turns():
    assert all(t["user"].strip() for t in SCEN["turns"])

def test_expected_answers_are_plain_substrings():
    for r in SCEN["recall"]:
        assert r["expected"] == r["expected"].strip()
        assert "," not in r["expected"]

def test_budget_needle_is_updated_and_recall_expects_new_value():
    budget = next(n for n in SCEN["needles"] if n["key"] == "budget_cap")
    assert budget["update_turn"] == 20 and budget["new_value"] == "35k"
    recall = next(r for r in SCEN["recall"] if r["needle_key"] == "budget_cap")
    assert recall["expected"] == "35"

def test_tool_outputs_at_turns_5_15_25_35():
    dumps = [t["index"] for t in SCEN["turns"] if t["tool_output"]]
    assert dumps == [5, 15, 25, 35]

def test_build_is_deterministic():
    assert build_scenario(seed=7) == build_scenario(seed=7)

def test_committed_json_matches_generator():
    committed = json.loads(Path("data/scenario.json").read_text(encoding="utf-8"))
    assert committed == build_scenario(seed=7)
```

### Task 2: Deterministic mock model

**Files:**
- Create: `src/__init__.py` (empty)
- Create: `src/mock_model.py`
- Create: `tests/test_mock_model.py`

**Interfaces:**
- Consumes: `Recall`, `Needle` shapes from Task 1 (plain dicts; no import needed).
- Produces:
  - `class MockModel` with `respond(context: list[dict], question: str) -> tuple[str, dict]`
  - `context` items are `{"role": "user"|"assistant"|"tool", "content": str}`.
  - Returned usage: `{"input_tokens": int, "output_tokens": int, "source": "synthetic"}`. Token count = `len(text.split())`.
  - Answer rule: find the key for `question` by matching against `NEEDLES` question text; search `context` **user** messages only (newest first) for the needle sentence; return the value found, else `"I do not know."`.

- [ ] **Step 1: Write the failing tests**

```python
# tests/test_mock_model.py
from src.mock_model import MockModel
from data.generate_scenario import build_scenario

SCEN = build_scenario(seed=7)
Q = next(r for r in SCEN["recall"] if r["needle_key"] == "manager")

def test_answers_from_context_when_fact_present():
    fact = next(t["user"] for t in SCEN["turns"] if t["index"] == 2)
    text, _ = MockModel().respond([{"role": "user", "content": fact}], Q["question"])
    assert Q["expected"] in text

def test_missing_fact_returns_unknown():
    text, _ = MockModel().respond([{"role": "user", "content": "hello"}], Q["question"])
    assert text == "I do not know."

def test_tool_output_does_not_answer():
    dump = "Calendar: manager 1:1 Priya Raman 10:00"
    text, _ = MockModel().respond([{"role": "tool", "content": dump}], Q["question"])
    assert text == "I do not know."

def test_usage_is_labelled_synthetic():
    _, usage = MockModel().respond([], Q["question"])
    assert usage["source"] == "synthetic" and isinstance(usage["input_tokens"], int)
```
